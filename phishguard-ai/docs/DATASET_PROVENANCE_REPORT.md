## 1. Executive Summary & Faculty-Ready Statement

### Formal Provenance Finding:
> **Original dataset provenance could not be verified from the available project files.**
> 
> The dataset currently present in the repository, `datasets/url_dataset_clean.csv` (7,330 rows), is **not** an external raw dataset directly downloaded from an academic repository, UCI, or Kaggle. Instead, source code inspection reveals that it is a **programmatically generated synthetic benchmark dataset** created locally by the project's data preparation pipeline (`backend/scripts/prepare_dataset.py`).

### Short Faculty-Ready Explanation (For B.Tech Report / Presentation):
> *"In the current implementation of PhishGuard AI, the URL training dataset (`url_dataset_clean.csv`, 7,330 entries) was programmatically generated using a pattern-based synthetic benchmark generator (`backend/scripts/prepare_dataset.py`). The pipeline was designed to ingest the public Kaggle 'Phishing Site URLs' archive (~550,000 URLs); however, in the absence of the raw 550k CSV in the repository, the script triggered its documented fallback generator. This generator synthesized 5,000 parameterized phishing URLs (incorporating known patterns like IP hosts, brand typosquatting, and high-risk TLDs) and 5,000 legitimate domain URLs, which deduplicated to 7,330 clean samples (2,330 benign, 5,000 phishing). While ideal for verifying end-to-end ML training pipelines, feature extraction, and API integration, production deployment requires ingesting genuine real-world feeds (e.g., PhishTank, OpenPhish, or the full Kaggle dataset)."*

## 3. Mathematical & Technical Evidence

### 3.1 Code Architecture in `backend/scripts/prepare_dataset.py`
The script defines a conditional load branch:
```python
if _RAW_CSV.exists():
    # Branch 1: Load and parse external CSV
    ...
else:
    # Branch 2: Fallback synthetic generation
    print(f"[dataset] Raw CSV not found at {_RAW_CSV}")
    print("[dataset] Generating synthetic dataset (10 000 URLs)…")
    rows = _generate_synthetic(5000, 5000)
```
Because `datasets/phishing_site_urls.csv` does **not** exist in the workspace, the pipeline took **Branch 2**.

### 3.2 The Exact Synthetic Templates
The phishing URLs in `url_dataset_clean.csv` match the exact string interpolation templates in `prepare_dataset.py`:
```python
_PHISH_PATTERNS = [
    "http://{rand}.{tld}/login/verify?id={nonce}",
    "http://{ip}/secure/update-account/{nonce}",
    "https://{rand}-{brand}.{tld}/signin/confirm",
    "http://{brand}.{rand}.{tld}/password/reset?token={nonce}",
    "http://{brand}-verify.{tld}/account/suspended/{nonce}",
    "http://{rand}.{tld}/{brand}/credential/{nonce}",
    "http://{ip}/{brand}/login.php?session={nonce}",
    "https://{rand}.{tld}/webscr?cmd=login-submit&dispatch={nonce}",
    "http://{rand}.{tld}/banking-secure/confirm/{nonce}",
    "http://{brand}-authenticate.{tld}:8080/verify/{nonce}",
]
_BRANDS = ["paypal", "apple", "microsoft", "google", "amazon", "netflix", "chase", "wellsfargo"]
_RANDOM_TLDS = ["xyz", "tk", "ml", "ga", "cf", "top", "buzz", "info", "click", "link"]
```

Sample records from `url_dataset_clean.csv`:
- Line 2: `http://164.176.108.250/secure/update-account/ccca50df7901e47e767,bad` *(Matches `{ip}/secure/update-account/{nonce}`)*
- Line 6: `http://137.155.111.82/paypal/login.php?session=ed78e514af5ae38328e2b1565,bad` *(Matches `{ip}/{brand}/login.php...`)*
- Line 12: `http://chase-verify.xyz/account/suspended/f9ec67f914fe2730b5a92902a1e8,bad` *(Matches `{brand}-verify.{tld}/account/suspended/...`)*
- Line 13: `https://88f9cb0815-google.buzz/signin/confirm,bad` *(Matches `{rand}-{brand}.{tld}/signin/confirm`)*

### 3.3 Deduplication & Sample Count Reconciliation
- Legitimate URLs were generated by combining 24 domains (`google.com`, `github.com`, etc.) with 14 paths and 4 scheme variants.
- Due to the limited combinatorial space of legitimate templates, deduplication (`seen.add(url)`) collapsed 5,000 attempts into **exactly 2,330 unique legitimate URLs**.
- Phishing URLs utilized randomized hexadecimal nonces (`hashlib.md5(randbytes).hexdigest()`), producing **5,000 completely unique phishing URLs**.
- **Total Dataset Size:** $2,330 + 5,000 = 7,330\text{ rows}$.

### 3.4 Model Training Split Verification (`models/url_detector_meta.json`)
The Random Forest model was trained with `test_size=0.20, stratify=y, random_seed=42`:
- Legitimate test samples: $20\% \times 2,330 = \mathbf{466}$
- Phishing test samples: $20\% \times 5,000 = \mathbf{1,000}$
- Total test evaluation samples: $466 + 1,000 = \mathbf{1,466}$
- This matches lines 36–45 of `models/url_detector_meta.json` byte-for-byte:
  ```json
  "confusion_matrix": [
    [466, 0],
    [0, 1000]
  ]
  ```
